# 原图与动效的植入规则

原课件里凡是“放图演示”的段落，成片里就应当出现那张图，而不是用文字或示意图替代。图不是背景装饰，是证据；看不清就等于没放。

## 1 什么时候必须放原图

脚本里出现下列信号，就把对应图片列为该镜的必备元素，并写进 `narration.json` 的 `asset` 字段：

- 脚本写了“参考图 0X”“课件第 X 页”“后台截图”“历史截图”；
- 旁白在指认图上的具体位置或数字（“这一根柱子”“红框里的几条”）；
- 讲对照、异常值、占比这类离开图就说不清的内容。

只做形式示意、且原图含不可用信息（主观评价、真人面部、账号名）时，可以不放原图，改用重绘示意图，并在依据表注明原因。

## 2 尺寸与可读性（硬约束）

以 1920×1080 为基准，单图展示必须同时满足：

| 项 | 阈值 | 说明 |
|---|---|---|
| 图宽 | ≥ 1150 px（画面宽 60%） | 两图并排时每张 ≥ 860 px（45%），否则改先后出场 |
| 图高 | ≥ 480 px，且不压字幕条 | 字幕区底部留 120 px |
| 图内正文字高 | ≥ 16 px | 换算：`缩放比 ≥ 16 / 原图正文字高`；1280 宽截图放到 1150 宽只有 0.9 倍，放到 760 宽是 0.59 倍，后者基本不可读 |
| 关键数字 | ≥ 22 px | 旁白点名的数字，必须能单独看清 |
| 局部放大倍数 | 建议 ≤ 2.2 倍 | 放大是为了让被点名的部分占屏足够大；超过 2.2 倍说明该拆成两次推近 |

## 2.1 完整展示与局部放大：两段，不是二选一

这是标准做法，也是最能突出重点的做法：

- **入场这一帧必须是完整的**。整图 contain 进白卡，不裁、不变形，让观众先知道“这是什么、有几条柱子、时间范围在哪”。
- **推近之后允许裁切，而且要裁得狠一点**。为了把要讲的那几条柱子、那个红框、那行数字放到能看清的尺寸，crop 窗口可以只留原图的 30%–50%，把周围无关的空白、导航栏、其他作品都切掉。这是“放大镜”，不是“截断”。
- **裁切只丢无关信息，不丢解释信息**。被点名数字所在的坐标轴、单位、时间范围要留在画面里，或者用角标补一句“图上为近 15 条作品”；不要出现一根没有任何刻度的柱子。
- **记住这是同一张图的两个阶段**。观众在 0.8 秒前刚看过全貌，推近时他不会迷路；如果一上来就放裁切图，才需要补缩略图或文字提示。

**原图分辨率不够时**：放大倍数不要超过 1.2 倍，宁可占屏略小也不要糊；短边不足 900 px 的图（如 800×632 的截图）放到 640–760 px 宽、配重绘示意图或局部标注来讲，不要把一张小图硬拉满屏。放大后依然看不清的，直接重绘数据图，并在依据表注明“原图分辨率不足，改为重绘”。

## 3 放图的三段式动效

1. **整图establish（0.5–0.8 s）**：整张图按 contain 放进白卡，先让观众看到全貌，透明度 0→1 淡入，轻微上浮 8 px。
2. **推近到证据点（1.5–2.5 s）**：用 crop 窗口推近到旁白指认的区域，同时保留 10% 的原图边缘作“位置提示”，避免观众失去上下文。推近速度 ≤ 每秒 1.15 倍。
3. **标注跟随（按分句触发）**：红框、箭头、数字标签跟着旁白分句渐显；同一时刻只亮一个标注，前一个降到 40% 不透明度。

对照类（两张图比较）优先做“先 A 后 B”的时间对照：A 缩到右上角做缩略图保留，B 放大到主位，旁白说“另一边……”时切过来。并排且都小于 860 px 宽的做法直接否掉。

## 4 实现约定

- `drawImg(c, key, x, y, w, h, crop, alpha)` 已经按 contain 等比缩放、居中留白，不会变形；缩放比由 `w` 决定，别把 `w` 设小。
- 需要放大时传 `crop = [x0, y0, wRatio, hRatio]`（归一化坐标），不要靠把整图放大到超出画面来“凑大”。
- 想把多图做成可复用组件，就统一走“白卡 + contain + crop 推近”这一套，卡片圆角 30 px，卡内留白 24 px。

**1920×1080 版式的实测可用坐标**（字幕条最高可到 y=888，标题基线 276）：

| 元素 | 值 |
|---|---|
| 大图区 | x 385–1535（宽 1150），y 336–860（高 524） |
| 阶段标签 | y 296–330，不在图上 |
| 底部补充说明 | 不要画在 y>864，会和字幕条打架；要讲的话放进标签或字幕 |
| 单图小于图区时 | 按 contain 居中，别拉伸 |

**局部放大的两个坑**：

1. 放大窗口切得太紧，会把要解读的播放数、日期、均值线切掉——先确认“旁白点名的数字在第几行”，crop 必须包含它。
2. 放大后画面变扁（三个横排作品放进 1150×524 只能取 1/3 高），看起来像纸带。宁可少放一个作品（2 个对 2 个），也要让封面完整、数字可读。


## 5 上线前检查（每张图都要过）

- [ ] 抽该镜中间一帧，量图内最小的正文/轴标签高度，≥16 px。
- [ ] 旁白点名的数字/红框在画面里能一眼找到，且没被裁掉。
- [ ] 图没被拉伸变形（看圆形是否变椭圆、柱宽是否一致）。
- [ ] 图与解说同步：说到的位置在同一分句内被点亮。
- [ ] 账号名、头像、后台字段的使用范围已在依据表登记。
