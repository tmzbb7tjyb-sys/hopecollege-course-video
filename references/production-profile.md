# production_profile 字段与默认值

开工时复制这份模板到工程根目录并填成可执行值，不写“清爽、清晰”这类形容词。

| 字段 | 默认值 | 说明 |
|---|---|---|
| profile_version | 1.0 | 每次改参数就升版，并在文末留变更记录 |
| 画幅与帧率 | 1920×1080 / 30 fps | 平台另有要求时覆盖 |
| 语速 | 330 字/分（约 1.5 倍） | 以用户选定样段为基准，逐段 atempo 归一 |
| 声音 | `zh-CN-XiaoxiaoNeural` | 全片一个音色；rate 粗调 + atempo 精调 |
| 配色 | 背景 `#E7E4FE→#EEF1FE→#F9FAFF→#FDECF1`；主文字 `#0F1826`；电蓝 `#1169FF`；青蓝 `#52E1FF`；紫 `#795CFF`；玫红 `#FF3D6E`（仅退回/缺证据/待确认） | 令牌写进代码常量，不靠自然语言反复猜 |
| 字体 | `Songti SC`，回退 `Hiragino Sans GB` / `STHeiti Medium` | 标题 68–82 px，关键数字 76 px，正文 ≥24 px，字幕 42 px |
| 版式集合 | 卡组 / 对比 / 结论 / 流程（按需） | 一屏一个焦点；卡片圆角 30 px |
| 画面参数 | Canvas 内部 3840×2160（2 倍），截帧 1920×1080 JPEG q88 | 逐帧由 `__render(t)` 决定 |
| 渲染方式 | 帧直通 ffmpeg（`-f image2pipe`） | 中间帧不落盘 |
| 音频参数 | 48 kHz / 双声道 / PCM 16-bit；成片 AAC 192k | −16 LUFS，TP ≤ −1 dBTP |
| 拼接方式 | 按 timeline 绝对时间拼单轨旁白 | 气口与读屏静留单独计入时间轴 |
| 留白 | 片头 0.8 s、镜间 0.7 s、片尾 1.6 s、读屏镜 +2.6 s | 读屏镜指图表/对照页 |
| 验收阈值 | 时长 ±0.3 s；响度 −16±1 LUFS；TP ≤ −1 dBTP；无黑帧、无截字 | 超出必须查音频尾、静帧或拼接 |
| 编码 | H.264 CRF 16（yuv420p）＋ AAC 192k | `-movflags +faststart` |
