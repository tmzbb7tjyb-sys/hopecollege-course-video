# 验收清单

顺序固定：事实 → 教学 → 旁白 → 分镜 → 技术。前面不通过就先改脚本，不要靠剪辑掩盖。

## 1 事实
- [ ] 每个关键数字、规则、案例编号都能回到依据表（ID 对得上）。
- [ ] 待确认项（口径、代表性、时效）在片里是“待确认”，没有讲成定论。
- [ ] 案例适用范围写清楚，不外推到所有账号/所有项目。
- [ ] 没有补造缺失数据；示意图和真实截图区分开。

## 2 教学
- [ ] 学习目标能检验：看完能在某情境下依据某证据完成某个判断。
- [ ] 每镜只回答一个问题，步骤能用到新案例上。
- [ ] 决策以“待确认/待核对”收尾时，学员知道下一步找谁确认。

## 3 旁白
- [ ] 全片一个音色；每段实测语速落在目标 ±3 字/分。
- [ ] 抽 1–2 段做转写核对，与脚本逐字一致（含英文缩写按字母读出）。
- [ ] 数字、术语处有气口，不赶；专有名词没有被改写成中文解释。

## 4 分镜
- [ ] 声音与画面落点按句界触发，字幕与旁白同一句话。
- [ ] 图表/对照页有足够读屏静留（≥2 s）。
- [ ] 字幕不遮挡主体，两行以内，底部留白一致。
- [ ] 屏上文字与旁白口径一致（改了旁白必须回头改屏上字）。

## 5 技术（先跑脚本，再看图）
- [ ] 时长与时间轴差 ≤0.3 s：`ffprobe -show_entries format=duration`
- [ ] 响度与峰值：
  `ffmpeg -hide_banner -i 成片.mp4 -af loudnorm=print_format=summary -f null -`
- [ ] 黑帧：`-vf blackdetect=d=0.08:pix_th=0.10`
- [ ] 缩略图墙：`bash scripts/contact_sheet.sh 成片.mp4 sheet.jpg`，一张图扫完重叠、截字、错页码
- [ ] 页码与总镜数由 `SCENES.length` 计算，删镜后编号不跳号
- [ ] 含视频段：`t_start-1 / t_start+1 / t_end-1 / t_end+1` 四个边界帧无黑场、无字幕断层，总时长＝场景段＋视频段
- [ ] 工程能重跑：文案改一处 → 重跑四步 → 成片时长随之变化

## 常见返工信号
- 时长比预估长几秒，且每段都长 → 配音把提示词念进去了。
- 字幕出现半句“……”、句末带“；” → 分句切在标点里，显示时要去掉句末标点。
- 某镜文案改了、画面没变 → 屏上字是硬编码的另一份。
